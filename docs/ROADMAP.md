# Roadmap

## Phase 1 — Project Foundation ✅

- Angular project initialization
- Documentation structure
- Domain models (TypeScript interfaces/enums)
- Feature-based folder structure
- SCSS design tokens
- Minimal app shell with bottom navigation
- PWA support (service worker, manifest)
- Dexie database schema stub

## Phase 2 — Domain and Persistence ✅

- Implement Dexie CRUD services for all entities
- Default single-user bootstrap
- Storage abstraction layer
- Unit tests for storage layer

## Phase 3 — Exercise Library ✅

- Seed built-in exercises
- Exercise list with search and filter
- Muscle group and equipment filters
- Custom exercise creation
- Exercise details screen

## Phase 4 — Workout Builder ✅

- Create/edit workouts
- Add/remove/reorder exercises
- Configure sets, reps, weight, rest, notes
- Workout program with weekly schedule
- Assign workouts to days

## Phase 5 — Active Workout

- Today's workout resolution
- Start/pause/resume/abandon workout
- Set tracking with metric inputs
- Previous performance display
- Rest timer service
- Skip sets/exercises
- Persist active session state

## Phase 6 — Workout History

- Completed workout list
- Workout detail view
- Exercise history per exercise

## Phase 7 — Progress

- Workout count, streaks, volume
- Personal records
- Exercise progression charts

## Phase 8 — Gamification

- XP on workout completion
- Streak tracking
- Milestones and stars
- PR celebrations

## Phase 9 — PWA/Offline Hardening

- Offline data access verification
- Service worker caching strategy
- Install prompt optimization

## Phase 10 — AI Capabilities

- Structured data export for analysis
- Weight/rep progression recommendations
- Stalled exercise detection
- Program adaptation

## Phase 11 — Social Capabilities

- Friends, leaderboards, challenges
- Trainer marketplace
