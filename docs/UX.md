# UX Guidelines

## Primary Context

Users interact while standing in a gym, holding a phone, potentially one-handed, wearing headphones, between exercises.

## Design Priorities

1. Large touch targets (44px minimum)
2. Minimal typing
3. Large numbers for weight, reps, timer
4. Clear current state
5. Obvious next action
6. Minimal navigation during workout
7. Fast set completion with strong feedback

## Screen Inventory (MVP)

1. Home / Today's Workout
2. Workout Details
3. Active Workout
4. Set Tracking
5. Rest Timer
6. Workout Complete
7. Workout Summary
8. Workout History
9. Exercise History
10. Progress
11. Workout Program
12. Workout Builder
13. Weekly Program Builder
14. Exercise Picker
15. Exercise Details
16. Profile / Settings

## Home Screen

Must answer: **"What should I do today?"**

Show: date, today's workout (prominent), exercise/set count, estimated duration, start button, streak, weekly completion, recent milestone.

## Active Workout (Highest Priority)

User must immediately see:
- Workout name, exercise number, current exercise
- Previous performance, target, current set, completed sets
- Weight/reps inputs, rest timer, next exercise

Preferred flow: Enter weight/reps → Complete Set → Rest Timer → Next Set

No unnecessary confirmation screens.

## Visual Direction

Modern, premium, athletic, clean, focused, slightly bold, motivating.

Avoid: excessive gradients/neon/glassmorphism, generic fitness dashboards, dense tables, tiny text.

## Responsive Targets

Primary: 375–430px mobile. Also support 320px, tablet, desktop. No horizontal overflow.

## Navigation

Bottom navigation for main sections: Home, Exercises, History, Progress, Settings. Active workout minimizes navigation.
